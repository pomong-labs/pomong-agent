# 🫧 Pomong Agent

**내 서버에 한 줄로 띄우는 개인 AI 비서 OS.**
BYOK 멀티 LLM · 서버 관제 · 암호화 금고 · 웹 푸시 · 완전한 셀프호스팅.

> A self-hosted personal AI assistant OS. Bring your own LLM key (Gemini · OpenAI · Claude),
> watch your server in real time, and keep secrets in a local AES-256-GCM vault.
> Everything runs on your own machine — no accounts, no telemetry, no vendor lock-in.

## v0.7.3 — 에이전트 명함 7대 개선 · 채팅 자동 전달 · 빈 화면 복구 (2026-11-21)

- **📱 iOS 시트 가림 해결** — 명함 편집 시트를 `z-100` 풀스크린 오버레이로 올려 하단 탭바 위에 두고, 상단 `env(safe-area-inset-top)+16px`·하단 `env(safe-area-inset-bottom)+20px` 안쪽에 붙였습니다. 맨 위 `명함 이름` 입력칸부터 맨 아래 저장 버튼까지 가려짐 없이 스크롤됩니다.
- **💬 채팅만으로 자동 완료·전달** — 손님 화면의 `용건·연락 남기기` 버튼과 시트를 없앴습니다. AI가 대화에서 정해 둔 항목을 하나씩 물어보고, 필수 항목이 다 차면 기계용 완료 블록(`[[COLLECT_DONE]]`)을 붙입니다. 서버가 이를 파싱해 **손님에게는 블록을 지우고 깔끔한 마무리 멘트만** 보여 주며, 요약을 저장하고 주인에게 웹 푸시로 전달합니다. 도구 0개 격리는 그대로입니다.
- **🧭 응답 방식 선택** — `delivery_mode`(`collect` = 대화 완료 시 전달 / `qna_only` = 지침 내 자유 Q&A · 전달 안 함). qna_only는 제출 유도·푸시·요약 없이 답변만 하고, 주인 화면에도 대화를 쌓지 않습니다.
- **🙋 1인 1회 참여** — `once_per_visitor`. 같은 방문자(IP 해시)가 이미 응답을 마쳤으면 새 세션을 열지 않고, 완료 즉시 손님 입력창을 **잠금 안내**로 바꿉니다(새로고침해도 유지). 대화형 설문 프리셋은 기본 ON.
- **🗓️ 보관 기간과 실제 삭제** — `retention_days`(0=영구, 기본 30일). 손님 입력창 아래 한 줄 안내와 **수집·처리 안내 모달**(수집 항목·목적·전달·보관·AI 처리)을 두고, 서버가 기동 직후와 6시간마다 `cleanupExpiredGuestData()`로 기간이 지난 세션·본문(IP 해시·연락처 포함)을 **DB에서 실제로 영구 삭제**합니다.
- **🤖 모델 드롭다운** — `이 명함만 쓸 모델`을 자유 입력에서 `<select>`로 바꾸고, `/api/agent-cards/models`가 **API 키가 연결된 프로바이더의 모델만** 내려 줍니다. `기본 모델 사용 (평소 쓰는 모델)`이 첫 항목입니다.
- **↩️ 뒤로가기·받은 응답 정리** — 헤더에 `더보기`로 돌아가는 뒤로가기 버튼을 추가했고, 받은 응답은 상태 배지(완료/진행중/차단)·참여 시각·턴 수·요약·항목별 표로 보여 주며 전체 대화는 접기/펼치기로 분리했습니다.
- **🌐 커스텀 도메인 안내 보강** — DNS 연결과 리버스 프록시(Cloudflare·Nginx·Caddy) SSL이 필요하고, 연결된 도메인에서는 공개 명함만 열리며 로그인·관리 화면은 404로 차단된다는 점을 입력칸 아래에 명시했습니다. 링크 복사와 QR도 그 도메인(`https://<domain>/c/<slug>`)을 씁니다.
- **🔒 qna_only는 흔적을 남기지 않음** — 전달 없이 답변만 하는 명함은 IP 해시도 DB 세션·본문도 저장하지 않고, 대화를 이어가기 위해 서버 메모리에 최대 2시간만 둡니다. 수집·처리 안내의 접속 기록·보관 문구도 이 동작과 일치합니다.
- **🔢 받은 응답 카운트·실시간 갱신** — `받은 응답 N건`은 자동 완료(`submitted`)만 세고, 새 응답 SSE 이벤트나 화면 복귀 시 목록과 카운트를 다시 읽습니다. 응답 카드에 항목 표가 있으면 같은 내용의 요약 박스는 생략되고 질문 라벨은 줄바꿈됩니다.
- **🖥️ 업데이트 직후 빈 화면 복구** — `/assets/*`처럼 없는 정적 파일은 index.html 대신 **404**로 응답하고, `/`·`sw.js`는 `no-cache, no-store, must-revalidate`로 나갑니다. 서비스워커는 화면 이동을 항상 네트워크 우선으로 처리하고 옛 캐시를 비우며, `vite:preloadError`·모듈 스크립트 로드 실패 시 **한 번만 자동 새로고침**(sessionStorage 가드)합니다.
- **🧪 검증** — `npm run typecheck`, `npm run build`, `npx tsx scripts/smoke-v073.ts`(자동 완료·잠금·1인 1회·qna_only·보관 삭제·모델 목록·보안 격리·정적 404·캐시 헤더·개인정보 비노출) 통과.

## v0.7.2 — 에이전트 명함(Agent Card) · 보안 방어 · 커스텀 도메인 격리 (2026-11-21)

- **🪪 멀티 용도 공개 명함** — 더보기 → **에이전트 명함**에서 내 포몽의 공개 명함을 여러 개 만들 수 있습니다. 용도 프리셋(**자기소개·Q&A / 미팅 일정 / 대화형 설문 / 커스텀**)을 고르면 소개문·안내 지침·추천 질문·받을 항목이 자동으로 채워집니다. 링크(`/c/<slug>`) 복사·QR 코드·공개 기간·세션당 턴 수·하루 응대 인원을 카드마다 정합니다.
- **👋 손님은 로그인 없이 대화** — `/c/<slug>` 는 주인 앱과 완전히 분리된 게스트 전용 화면입니다(사이드바·하단 탭바·모델 선택바·첨부 없음). 마스코트 + `피몽 | ● 응대 가능` 유리 캡슐 + 우측 `공개 명함 · 남은턴/20` 배지, 추천 질문 칩, 말풍선, **용건·연락 남기기** 시트로 구성됩니다. 새로고침해도 이 브라우저의 대화가 이어집니다.
- **🛡️ 도구·기억 완전 격리** — 게스트 대화는 **도구 0개**(`tools: []`)로 호출합니다. 주인의 기억·금고·메일·브라우저·쉘·파일은 컨텍스트에 들어가지 않고, 그 명함의 소개문·안내 지침만 시스템 프롬프트가 됩니다.
- **💸 LLM 호출 전 0원 필터** — 500자 길이 제한, 욕설·비속어, 같은 글자·문장 도배, 프롬프트 인젝션(`ignore previous`·`system prompt`·`jailbreak`·`규칙 무시` 등)을 서버가 먼저 걸러 **토큰을 쓰지 않고** 안내문을 돌려줍니다. IP 분당 요청 한도, 세션당 최대 턴, 명함별 하루 인원 한도도 함께 동작합니다.
- **🔐 PIN · 만료 · 요약 알림** — 명함마다 PIN(4~12자리, 해시 저장)과 공개 종료일을 둘 수 있습니다. 손님이 용건을 남기면 대화 내용을 3~5줄로 정리해 저장하고 **웹 푸시 알림**으로 알려 주며, 알림을 누르면 그 명함의 받은 대화로 바로 갑니다.
- **🌐 커스텀 도메인 격리** — 명함에 `card.example.com` 같은 도메인을 등록하면, 그 도메인으로 들어온 요청은 `/`, `/c/:slug`, 에셋·공개 API만 열리고 `/login`·`/api/vault/*`·`/api/chat/*`·`/api/memory/*`·`/api/settings/*`·관리 API는 **전부 404**로 막힙니다. 주소를 몰라도 관리 화면에 닿을 수 없습니다. 메인 서비스 호스트는 `MAIN_HOSTS` 환경변수로 정합니다.
- **📊 게스트 턴도 관측성에 기록** — 손님 대화도 `card:<slug>` 세션으로 실행 트레이스에 남아 토큰·비용을 다른 작업과 함께 볼 수 있습니다.
- **🧪 검증** — `npm run typecheck`, `npm run build`, `npx tsx scripts/smoke-v072.ts`(스키마·CRUD·0원 필터·한도·PIN·제출·실서버 도메인 404·개인정보 비노출) 통과.

## v0.7.1 — 워크플로우 빌더 · 하이브리드 기억 · 알림 딥링크 · 기억 그래프 (2026-11-21)

- **🧩 단계별 워크플로우 빌더** — 도구(스킬) 관리의 커스텀 도구가 **[글로 쓰기] / [단계별 조립]** 두 모드가 됩니다. 단계는 ① `도구`(내장 도구를 토큰 소모 없이 서버가 직접 실행) ② `AI`(이전 단계 결과를 현재 모델이 요약·가공) ③ `알림 · 할 일`(웹 푸시 또는 할 일 등록) 세 가지이며, `{{input}}`·`{{step1}}` 변수 칩을 눌러 바로 꽂을 수 있습니다. 저장 전 **[테스트 실행]** 으로 단계별 출력·소요시간을 확인하고, 목록 카드의 **[▶ 실행]** 으로 즉시 돌릴 수 있습니다. AI는 `run_workflow` 도구로 저장된 워크플로우를 이름으로 실행합니다. 기존 프롬프트 도구는 그대로 동작합니다(무손실 마이그레이션).
- **🧠 기억 검색 정밀도 — 하이브리드 점수** — 키워드(BM25) + 글자 n-gram 코사인 + 최신성(시간 감쇠) + 중요도를 합쳐 대화 맥락에 가장 관련 높은 기억만 프롬프트에 넣습니다. 중요도를 4~5로 올리거나 **[중요 고정]** 한 기억은 매 대화에 항상 들어갑니다.
- **🕰️ 기억 최신화 — 대체·병합** — 같은 주제의 새 기억이 들어오면 옛 기억을 지우지 않고 `superseded_by` 로 표시해 프롬프트에서만 빠지게 합니다. **[중복 정리]** 로 한 번에 정리하고, 잘못 대체된 기억은 복원할 수 있습니다(행 보존).
- **🔗 알림 딥링크** — 웹 푸시 알림(예약 완료·워치 변경·택배 이동·승인 요청)에 `?room=<방>&msg=<메시지>&approval=<카드>` 딥링크가 붙습니다. 알림을 누르면 열려 있는 창은 그대로 둔 채 서비스워커가 화면에 알려 주고, 해당 대화방으로 전환해 그 말풍선·승인 카드까지 내려가 잠깐 강조합니다. 창이 없으면 딥링크로 새 창을 엽니다.
- **🛡️ 2단계 인증 중 로그인 카드 중복 노출 차단** — 2단계 인증(OTP)·캡차·패스키·이메일 인증 화면이 떠 있거나 사용자가 브라우저 화면을 넘겨받은 상태에서는 `vault_request_login`(로그인 카드)이 다시 뜨지 않습니다. 세션에 마지막 인증 화면 종류를 기억해 두고(주소·화면 문구로도 판별) 카드 생성 전에 확인하며, 차단 시 "브라우저 화면에서 인증을 마쳐 주시면 바로 이어서 진행할게요"로 안내합니다.
- **♻️ 인증 마치면 AI가 알아서 이어서 진행** — 브라우저 전체화면에서 인증을 마치고 **[인증 완료 · 이어서 진행]** 을 누르면, 그 대화의 에이전트 턴이 자동으로 재개됩니다(사용자가 "다 됐어"를 칠 필요 없음). 현재 화면을 확인해 인증이 끝났으면 직전 작업의 다음 단계부터 이어 가고, 아직 남아 있으면 다시 화면을 넘깁니다. 20초 쿨다운·진행 중 턴·대화 기록 없음 가드로 중복 실행을 막고, 취소를 누르면 재개하지 않습니다.
- **💬 작업 중 내 말풍선이 사라지지 않음** — 요청을 보내면 서버가 에이전트 루프를 돌리기 **전에** 사용자 메시지를 DB에 저장하고 바로 화면(SSE)에도 알립니다. 화면은 맨 아래를 보고 있을 때만 자동으로 따라 내려가고, 작업 카드·스트리밍 답변이 자라날 때 방금 보낸 내 말풍선을 위로 밀어내지 않습니다.
- **🕸️ 개인 지식 그래프** — 기억함에서 **[내 기억 그래프]** 로 들어가면 `나 → 분류(사람·프로젝트·취향·약속·일정…) → 기억` 구조를 SVG 네트워크로 보여 줍니다. 분류 필터·검색, 드래그 이동·핀치/휠 확대, 노드 탭 상세 카드에서 **[연결 편집]**(기억끼리 잇기·해제)과 **[중요 고정]** 을 할 수 있습니다.

## v0.6.18 — 승인 카드 · 개인정보 마스킹 · 가드레일 · 음성 메모 (2026-11-21)

- **🛑 민감 작업 승인 카드(Human-in-the-Loop)** — 도커 컨테이너의 중지·재시작·시작·일시정지처럼 되돌리기 어려운 도구는 실행 직전에 멈추고 채팅에 **[승인 / 취소] 카드**를 띄웁니다. 승인을 누르면 서버가 그 도구를 실제로 실행해 결과를 말풍선으로 남기고, 취소하면 그대로 둡니다. 승인 요청은 DB(`pending_approvals`)에 남아 새로고침해도 유지되며 10분 뒤 스스로 만료됩니다.
- **🕶️ 외부 AI 전송 전 개인정보 마스킹** — 설정에서 켜면(기본 ON) Gemini·OpenAI·Claude·EXAONE로 보내기 직전에 전화번호·계좌번호·카드번호·주민등록번호·이메일을 `[전화번호 1]` 같은 표시로 바꿔 보내고, 답변·도구 인자는 서버가 원래 값으로 되돌립니다. 대화 전체를 같은 순서로 훑어 번호를 매기므로 단계가 이어져도 같은 값은 같은 번호입니다.
- **🧱 프롬프트 인젝션 · 피싱 URL 가드레일** — 웹페이지 본문·첨부 문서·이메일처럼 바깥에서 온 글을 AI 컨텍스트에 넣기 전에 "이전 지시를 무시해" 류 지시문을 가리고, IP·푸니코드·브랜드 사칭·단축 링크는 `[피싱 의심]` 으로 표시합니다.

## v0.6.17 — 리소스 프리로드 · 캐릭터 깜빡임 제거 (2026-11-21)

- **⚡ 마스코트 리소스 프리로드** — 앱이 부팅하는 순간(스플래시가 떠 있는 동안) 모든 마스코트 PNG(기본·히어로·소품 16장)와 상태별 표정 PNG(6캐릭터 × 5상태 30장)를 `Image` + `img.decode()` 로 미리 받아 디코드해 둡니다. 상태가 바뀌는 순간 네트워크를 기다리지 않고 바로 그려집니다.
- **🛡️ 스플래시 무한 대기 방지** — 스플래시는 최소 620ms 보여 준 뒤 **핵심 이미지가 준비되면** 넘어가고, 네트워크가 느려도 **최대 1.6초**에서 끊고 앱으로 넘어갑니다. iOS `standalone` PWA처럼 중복 스플래시를 생략하는 환경에서도 부팅 직후 백그라운드 프리로드 + `decode()` 가 똑같이 돌아 첫 상태 전환부터 지연이 없습니다.
- **🐣 캐릭터 1프레임 깜빡임 제거** — 이전에는 표정이 바뀔 때 `key={src}` 로 새 `<img>` 를 만들어, 첫 프레임에 이전 그림이 없고 새 그림이 `opacity: 0` 에서 시작해 캐릭터가 한 프레임 사라졌습니다. 지금은 캐릭터의 다섯 상태 그림을 **항상 겹쳐 둔 layer** 로 유지하고 `opacity`·`scale` CSS transition(550ms · `cubic-bezier(0.22,1,0.36,1)`)만 바꿉니다. 새 그림이 아직 준비되지 않았으면 이전 표정을 그대로 보여 주므로 빠른 연속 상태 변화에도 빈 프레임이 생기지 않습니다.
- **적용 범위** — 상단 헤더 · 설정 · 자동화 · 할 일 · 설치 마법사 등 `MascotFace` 를 쓰는 모든 화면.

## 왜 만들었나

기존 AI 비서는 대화 내용이 남의 서버로 가고, 모델과 한도를 서비스가 정합니다.
Pomong Agent는 반대로 갑니다.

- **내 서버에서만 동작** — 대화·메모·비밀번호가 내 디스크를 떠나지 않습니다.
- **BYOK (Bring Your Own Key)** — Gemini · OpenAI · Claude 중 원하는 모델을 골라 연결합니다. 한도는 내 키의 한도일 뿐입니다.
- **서버를 함께 봅니다** — CPU·RAM·Disk 실측, 상위 프로세스, 시스템 로그를 채팅 안에서 바로 확인합니다.
- **금고** — API 키와 로그인 정보를 PIN으로 잠그고 AES-256-GCM으로 암호화해 보관합니다.
- **포몽이 캐릭터** — 서버가 힘들면 함께 걱정해 주는 6종 마스코트.

| 답변 읽어주기(TTS) | AI 답변의 `복사` 옆 `듣기`/`멈춤` 버튼으로 `speechSynthesis`(ko-KR)가 마크다운을 걷어 낸 문장을 읽습니다. 다른 답변을 누르면 이전 재생은 자동으로 멈추고, 긴 답변은 문장 단위로 잘라 iOS에서도 끊기지 않게 읽습니다. |

## 빠른 시작 (Docker)

```bash
git clone https://github.com/pomong-labs/pomong-agent.git
cd pomong-agent
cp .env.example .env      # optional — 기본값으로도 동작합니다
docker compose up -d --build
```

기동 후 **1회용 설정 주소**를 확인합니다.

```bash
docker compose logs pomong-agent | grep -o 'http://[^ ]*setup?token=[A-Za-z0-9_-]*'
```

그 주소를 브라우저에서 열고 4단계를 마치면 `/setup`은 잠기고, 이후에는 `/login`으로 접속합니다.
기본 포트는 `127.0.0.1:3100`(루프백)입니다. nginx 등으로 80/443에 붙이세요.

```nginx
server {
    listen 80;
    server_name agent.example.com;

    client_max_body_size 10m;
    location / {
        proxy_pass http://127.0.0.1:3100;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

HTTPS는 `certbot --nginx -d agent.example.com`로 마무리합니다.

## 구조

```
src/            React + TypeScript + Tailwind UI (Setup · Chat · Monitor · Vault · Tasks · Automation · Browser · Settings)
server/         Express + TypeScript API, SQLite(better-sqlite3), AES-256-GCM 금고, 시스템 샘플러
server/system.ts  /proc 기반 CPU·RAM·Disk·프로세스 수집기
server/jobs.ts    예약 실행 스케줄러 (croner, job_runs 기록, 따라잡기·겹침 정책)
server/watchers.ts 웹 변화 감시 (cheerio 추출, 해시 비교, diff·백오프)
server/browser.ts 자율 브라우저 세션·핸드오버·입력 브리지 (playwright-core)
server/policy.ts  도메인 정책·결제 하드블록·프롬프트 인젝션 감지
docker/Dockerfile.browser  브라우저 워커 이미지 (Playwright run-server)
public/mascots/   포몽 6종 마스코트 (앱 렌더링용)
brand/            마스코트 원본 시트 · 에셋 라이선스
scripts/          install.sh 등 운영 스크립트
```

데이터는 모두 `./data` 하나에 모입니다.

```
data/pomong-agent.db   SQLite (설정·대화·금고 암호문·할 일·로그)
data/setup-token.txt   1회용 설정 토큰 (설정 완료 시 자동 삭제)
data/.server_key       API 키 암호화 키
data/.session_key      세션 서명 키
data/.vault_key...     금고 마스터 키 (PIN으로 감싼 형태)
```

**`./data`만 백업하면 전체 상태가 복구됩니다.** 이 폴더는 절대 커밋하지 마세요.

## 보안 요약

- 비밀번호: `scrypt` 해시 (평문 저장 없음)
- API 키: AES-256-GCM, 서버 로컬 키로 암호화
- 금고: PIN → scrypt → 키 유도, 마스터 키는 PIN으로 감싸 보관, 10분 자동 잠금
- 세션: HMAC 서명 쿠키 (HttpOnly · SameSite=Lax · HTTPS에서 Secure)
- `/setup`은 1회용 토큰 + 완료 후 410 잠금, 로그인 8회 실패 시 15분 차단
- 외부 전송은 **선택한 LLM 제공자 API 호출 외에 없습니다** (텔레메트리 없음)

자세한 내용과 신고 절차는 [SECURITY.md](SECURITY.md)를 봐 주세요.
